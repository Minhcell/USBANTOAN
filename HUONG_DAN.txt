  USB AN TOAN - Giao dien giong H04 (1 FILE EXE, build GitHub)
================================================================

Ket qua: 1 file duy nhat USB_AN_TOAN_Setup.exe
Giao dien: giong het H04 (thanh cong cu, 2 khung, mui ten xanh)
Bao mat: AES-256, du lieu an, CHAN copy truc tiep (lap day 0 byte)

----------------------------------------------------------------
BUOC 1: Tao repository tren GitHub (mien phi)
----------------------------------------------------------------
https://github.com > dang ky > New repository > dat ten > Create

----------------------------------------------------------------
BUOC 2: Upload code
----------------------------------------------------------------
Giai nen file nay, keo 2 thu vao khung upload cua GitHub:
  - vault_drive.py
  - thu muc .github
Bam "Commit changes"

  * Neu khong keo duoc .github:
    Add file > Create new file > go ten: .github/workflows/build.yml
    Dan noi dung file build.yml vao > Commit

----------------------------------------------------------------
BUOC 3: Cho build (5-7 phut)
----------------------------------------------------------------
Tab "Actions" > cho tich XANH

----------------------------------------------------------------
BUOC 4: Tai file EXE
----------------------------------------------------------------
Bam lan build xong > keo xuong "Artifacts" > tai ve > giai nen
=> 1 file USB_AN_TOAN_Setup.exe

----------------------------------------------------------------
BUOC 5: Dung
----------------------------------------------------------------
1. Chuot phai USB_AN_TOAN_Setup.exe > Run as administrator
2. Chon USB > dat mat khau dang nhap > KHOI TAO
   (Setup se: tao partition nho chua EXE, LAP DAY 0 byte de
    chan copy truc tiep, dat vung du lieu an AES-256)
3. Rut USB, cam lai > chay USB_AN_TOAN.exe tren USB
4. Dang nhap > dat mat khau ma hoa > dung

----------------------------------------------------------------
CACH DUNG (giong H04):
----------------------------------------------------------------
- Chon file ben trai (MAY TINH) > bam mui ten XANH sang phai
  => ma hoa & copy vao USB
- Chon file ben phai (USB) > bam mui ten XANH sang trai
  => giai ma & copy ve may
- Nhan dup file tren USB de mo xem
- Tao thu muc / Doi ten / Xoa du lieu: thanh cong cu tren
- Doi mat khau / Format USB: thanh cong cu tren

----------------------------------------------------------------
CHAN COPY TRUC TIEP (giong H04):
----------------------------------------------------------------

"There is not enough space" (0 byte trong) - dung nhu H04.
